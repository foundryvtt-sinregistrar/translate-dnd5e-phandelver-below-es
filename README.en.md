# 🇬🇧 Phandelver and Below — Spanish Translation (Babele)

Spanish translation for the official Foundry VTT module **Phandelver & Below: The Shattered Obelisk**.

## Requirements

- Foundry VTT 13 or 14
- dnd5e system 5.3.1 or later
- Babele 2.7.5 or later
- Official `dnd-phandelver-below` module 3.1.0 or later

## Installation

Install this module and its dependencies, enable them in your world, and select Spanish as the Foundry VTT language.

## Status

This project is in its initial stage. Translation files for all five official compendiums are ready to receive entries.

This project does not include or redistribute content from the original commercial module.
